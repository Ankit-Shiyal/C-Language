
📘 C Language Array & Matrix Programs

This repository contains a collection of C language programs focused on arrays and 2D matrices. These programs are commonly asked in college practicals, assignments, and exams, and help build a strong foundation in loops, arrays, and matrix operations.

🔹 Programs Included

1️⃣ Find Negative Elements in an Array

Takes array size and elements from the user

Identifies and prints all negative numbers

Uses 1D array and for loop

Concepts Used:

Array input/output

Conditional statements

Loops
