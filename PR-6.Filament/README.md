📘 C Language String Programs

This repository contains C language programs based on string manipulation. These programs are useful for college practicals, lab work, and understanding core string concepts in C without using built-in string functions.

🔹 Programs Included

1️⃣ Palindrome String Check

  Takes a string as input from the user

  Reverses the string manually

  Compares original and reversed strings

  Checks whether the string is a palindrome

Example:

  Input: nayan → ✅ Palindrome

  Input: ankit → ❌ Not a palindrome

Concepts Used:

  Character arrays

  String traversal using loops

  Manual string reverse

  Conditional statements
